# Serviço de Exportação e Formatação de Dados (Meals)

Aplicação desenvolvida em Java para processamento, formatação e exportação de dados estruturados em múltiplos formatos.

## 🛠️ Tecnologias Utilizadas
- Java
- Manipulação de Arquivos e Estruturas de Dados
- Formatação em CSV / JSON / XML

## 📌 Funcionalidades
- Leitura e organização de dados de entrada.
- Conversão e exportação para formatos padronizados.
